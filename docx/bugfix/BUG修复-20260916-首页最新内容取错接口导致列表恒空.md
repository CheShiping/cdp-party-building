# BUG 修复 · 20260916 · 首页「最新内容」取错接口导致列表恒空

- 影响功能：feat-007 首页「最新内容」区块
- 严重级别：低（页面不报错，但区块恒显空态）
- 状态：已修复并验证

## 1. 现象

首页「最新内容」区块恒显示 `AppEmpty`（暂无内容），而专题宫格点进去的列表页却有内容。

## 2. 复现步骤

1. 登录进入首页；
2. 观察「最新内容」区块 → 始终"暂无内容"；
3. 点击专题宫格任一子专题 → 列表页有图文数据。

## 3. 根因

后端图文类别是**两级结构**，类别 3「专题学习」是**父类别**，其内容挂在子类别（4~9）上：

```bash
# 实测（2026-09-16）
GET /apituwen/tuwenliebiao?tuwenleibieid=3   → list 长度 0   ← 原实现用的接口
GET /apituwen/tuwenfuliebiao?tuwenleibieid=3 → list 长度 5   ← 正确接口（父类别全部图文）
GET /apituwen/tuwenliebiao?tuwenleibieid=6   → list 长度 2（子类别有数据）
```

原实现用 `apiTuwenLiebiao(TUWEN_CATEGORY.TOPIC /* 3 */, …)` 取"最新内容"，而 `tuwenliebiao` 只查**该类别自身**的图文，故恒为空。

## 4. 修复方案

`src/pages/index/index.vue` 中「最新内容」改用 `apiTuwenFuliebiao(TUWEN_CATEGORY.TOPIC, 1, 10)`（父图文全部列表，接口文档第 3 条），并在注释中写明"实测类别 3 自身无直接图文"。

## 5. 改动文件

- `src/pages/index/index.vue`（最新内容数据源替换 + 注释）
- `src/api/modules/tuwen.ts`（新增 `apiTuwenFuliebiao`，落地 `tuwenfuliebiao` 契约）

## 6. 回归验证结果

| 项 | 结果 |
|---|---|
| 接口实测 | `tuwenfuliebiao?tuwenleibieid=3&page=1&pagesize=5` → 5 条（含标题/摘要/日期/wenjianurl） |
| 类型检查 / Lint | `npx vue-tsc --noEmit` → 0 error；`npm run lint` → 0 error 0 warning |
| 构建 / 产物自检 | `npm run build:mp-weixin` → `DONE Build complete.`；`npm run check:pages` → `ALL PAGES OK` |
| 目视回归 | 待用户在开发者工具确认首页「最新内容」出现 5 条图文并可点入详情 |

## 7. 备注

- 父类别 3 的图文自带 `settuwenleibieid`（实测为 8/7/5 等子类别），详情跳转必须带上该真实子类别 id，否则 `tuwenxiangqing` 会返回残缺对象（详见 feat-008 设计文档 §2.1）。
