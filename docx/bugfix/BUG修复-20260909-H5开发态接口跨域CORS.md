# BUG 修复 - 20260909 - H5 开发态接口跨域（CORS）

## 现象

浏览器访问 H5 开发服（`http://localhost:5173`）登录页提交后，控制台报：

```
Access to XMLHttpRequest at 'https://szdj.cdszxjc.com/apiuser/login?...' from origin 'http://localhost:5173'
has been blocked by CORS policy: Response to preflight request doesn't pass access control check:
No 'Access-Control-Allow-Origin' header is present on the requested resource.
GET https://szdj.cdszxjc.com/apiuser/login?... net::ERR_FAILED
```

请求层提示「网络异常，请检查跨域或代理配置(request:fail)」，登录失败。

## 复现步骤

1. `cd cdp-party-building-uniapp && npm run dev:h5`
2. 打开 `http://localhost:5173/#/pages/login/index`
3. 输入账号密码登录 → 触发上述 CORS 报错

## 根因

- H5 端 `API_BASE_URL` 直接取 `.env` 的绝对地址 `https://szdj.cdszxjc.com/`，浏览器从 `localhost:5173` 发起跨域请求；
- 后端（`szdj.cdszxjc.com`）未返回 `Access-Control-Allow-Origin` 响应头（含预检 OPTIONS），浏览器拦截；
- 小程序端无同源策略限制，不受影响，因此该问题只在 H5 开发态暴露。

## 修复方案

H5 开发态改为「同源请求 + Vite dev server 代理转发」，小程序/App 端保持绝对基址直连：

1. `vite.config.ts`：新增 `server.proxy`，将 `/apituwen`、`/apiliuyan`、`/apiuser` 三个模块前缀代理到 `https://szdj.cdszxjc.com`（`changeOrigin: true`）。
2. 新增 `.env.development`：`VITE_H5_BASE_URL=` 留空 → H5 开发态基址为空（同源），由代理转发；`.env` 中生产用绝对地址不变。
3. `src/constants/api.ts`：`API_BASE_URL` 按平台取值 —— H5 端取 `VITE_H5_BASE_URL`，小程序/App 端取 `VITE_BASE_URL`。
4. `src/api/modules/user.ts`：`apiTouxiang`（头像上传）原先直接读 `VITE_BASE_URL` 绕过了平台取值逻辑，改为统一使用 `API_BASE_URL`。

影响面：`resolveFileUrl` 拼出的图片地址在 H5 开发态为相对路径（`/apituwen/...`），同样经 dev server 代理访问，行为一致。

## 改动文件

- `cdp-party-building-uniapp/vite.config.ts` — 新增 `server.proxy`（三个模块前缀）
- `cdp-party-building-uniapp/.env.development` — 新增（`VITE_H5_BASE_URL` 开发态置空）
- `cdp-party-building-uniapp/src/constants/api.ts` — `API_BASE_URL` 平台化取值
- `cdp-party-building-uniapp/src/api/modules/user.ts` — `apiTouxiang` 改用 `API_BASE_URL`

## 回归验证结果

- `npm run type-check`（vue-tsc --noEmit）→ exit 0，0 error
- 小程序端不受影响：mp 端仍取 `.env` 绝对基址（待用户在开发者工具重编确认渲染）
- H5 端待验证：重启 `npm run dev:h5` 后登录请求应变为 `http://localhost:5173/apiuser/login?...`（同源，经代理转发，无 CORS）

## 遗留问题

- H5 **生产构建**仍为绝对基址直连，需后端开启 CORS 响应头，或 H5 部署侧配置反向代理（如 Nginx 同域转发 `/apiuser` 等前缀）后再将 `VITE_H5_BASE_URL` 置空。
- `vite.config.ts` 变更需重启 dev server 才生效。
