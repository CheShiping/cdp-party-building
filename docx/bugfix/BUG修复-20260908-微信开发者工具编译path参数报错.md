# BUG 修复：微信开发者工具编译报 `The "path" argument must be of type string. Received undefined`

日期：2026-09-08

## 现象

首次在微信开发者工具中打开 `dist/dev/mp-weixin`（appid `wxYOUR_APPID_PLACEHOLDER`）编译时，工具抛错并中断：

```
TypeError [ERR_INVALID_ARG_TYPE]: The "path" argument must be of type string. Received undefined
    at Object.join (node:path:1172:7)
    ...
    at SummerCompiler._getPackageFiles (…/summerCompiler.js:2:2648)
    at SummerCompiler.getAllPageAndComponent (…)
```

页面无法编译、模拟器无内容输出。

## 复现步骤

1. `cd cdp-party-building-uniapp && npm run dev:mp-weixin`
2. 微信开发者工具导入 `dist/dev/mp-weixin` 并编译
3. 观察编译进程崩溃，日志见上述堆栈

## 根因

编译产物中，部分页面 WXML 使用了自定义组件标签，但其页面 JSON 的 `usingComponents` 为空，开发者工具无法把标签映射到组件文件，内部 `path.join(undefined)` 崩溃。

产物对比（修复前）：

- `pages/index/index.json` → `usingComponents` 含 `app-button` ✅
- `pages/list/index.json` → `usingComponents: {}`，但 `index.wxml` 使用 `<app-navbar>/<app-button>/<app-empty>/<app-card>` ❌
- `pages/form/index.json` → `usingComponents: {}`，但 `index.wxml` 使用 `<app-card>/<app-input>/<app-button>` ❌

差异源头在源码写法：`index.vue` 直接 `import AppButton from '@/components/AppButton/AppButton.vue'`（编译器可静态识别 → 正确写入 JSON）；而 `list.vue` / `form.vue` 是 `import { AppButton } from '@/components/AppButton'`（经桶文件 `index.ts` 命名导入，编译器无法把模板组件解析进 JSON）。

## 修复方案

模板用到的自定义组件统一改为**直接导入 `.vue` 文件（默认导出）**，与 `index.vue` 一致，使编译产物正确生成 `usingComponents`：

- `src/pages/list/index.vue`：`AppNavbar / AppButton / AppEmpty / AppCard` 四个组件由 `@/components/AppX` 桶导入改为 `@/components/AppX/AppX.vue` 默认导入
- `src/pages/form/index.vue`：`AppButton / AppCard / AppInput` 三个组件同样改法

（组件目录的 `index.ts` 桶文件保留，供非模板场景引用；页面模板组件必须直连 `.vue`。）

## 改动文件

- `cdp-party-building-uniapp/src/pages/list/index.vue`
- `cdp-party-building-uniapp/src/pages/form/index.vue`
- `docx/BUG修复-20260908-微信开发者工具编译path参数报错.md`（本文件）
- `progress.md`（会话日志同步）

## 回归验证结果

1. 运行中的 `npm run dev:mp-weixin` 监听自动重编产物后核对：
   - `dist/dev/mp-weixin/pages/list/index.json` → `usingComponents` 含 `app-button / app-card / app-empty / app-navbar`
   - `dist/dev/mp-weixin/pages/form/index.json` → `usingComponents` 含 `app-button / app-card / app-input`
   - 对应组件产物 `components/AppNavbar|AppButton|AppEmpty|AppCard|AppInput/` 四件套（`.js/.json/.wxml/.wxss`）齐全
