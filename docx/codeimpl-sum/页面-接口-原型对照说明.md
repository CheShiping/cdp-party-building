## 4. 无接口部分：界面呈现 vs 数据边界

> 原则（AGENTS.md）：**界面按原型做全，数据不编造**。

| 位置 | 界面（已按原型呈现） | 不做 / 不编造 |
|---|---|---|
| 党员服务「近期活动」 | 活动卡：封面上图 + 活动标签 + 标题 + 摘要 + 日期 + 报名按钮 | 报名/签到/我的参与记录/地点/人数/报名状态 |
| AI 学习页 | 搜索 + 分类 chips + 图文卡片列表（真实数据） | 数智党建手册、知识库专区、学习进度、AI 问答 |
| 个人中心 积分卡 | 暖底卡 + 我的积分 / 支部排名 + 占位「—」 | 积分数值、支部排名数值、积分规则 |
| 首页 VR 基地 | 入口按钮 | 全景场景、热点讲解 |
| 电子档案 档案导出 | 底部按钮 | 导出能力 |
| 档案详情 档案材料 | 区块 + 空态说明 | 入党申请书 / 思想汇报归档数据 |
| 个人中心 我的活动/学习台账/应知应会 | 菜单项 + 点击说明 | 对应数据与页面 |
| 内容详情 正文内链接 | 正文渲染 + 「查看原文」 | 正文内节点跳转（`rich-text` 能力限制） |

## 5. 关键实现约定（跨页面）

1. **图片**：接口值优先（`obj.ossdir` + `wenjianurl`），失败/为空才落 `src/static/` 兜底图，两者都无 → `AppEmpty`。
2. **鉴权**：业务接口 Header `token`；token 超 24h 静默续期；401 统一登出。
3. **组件导入**：必须 `import X from '@/components/X/X.vue'`（桶导入会导致小程序产物缺 `usingComponents`）。
4. **样式**：颜色/字号/间距一律走令牌，`npm run theme:check` 门禁。
5. **产物自检**：`npm run build:mp-weixin` + `npm run check:pages`（12 页 `ALL PAGES OK`）。
6. **主包预算**：当前 1684.4 KB / 2048 KB；`src/static/` 下未引用文件同样计入主包，勿放预留资源。
